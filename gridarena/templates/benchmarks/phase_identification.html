Prediction JSON Format

The prediction file should be a JSON object mapping anonymised keys to predicted phases:

{
  "anon_key_a1b2": "R",
  "anon_key_c3d4": "S",
  "anon_key_e5f6": "T",
  ...
}

Keys must match those returned by the Download Phase Data endpoint. Values must be one of "R", "S", or "T".

The Submission ID and Grid ID from Benchmark Setup are added automatically. The full request sent to the API is:

{
  "guess_id": "your_submission_id",
  "grid_id": "your_grid_id",
  "guesses": {
    "anon_key_a1b2": "R",
    "anon_key_c3d4": "S",
    "anon_key_e5f6": "T"
  }
}

See API Docs for the full schema specification.
