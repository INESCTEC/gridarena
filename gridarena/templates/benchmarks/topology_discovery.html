Prediction JSON Format

The prediction file should be a JSON object with guess_id, grid_id, and guesses (a list of edge pairs):

{
  "guesses": [
    [0, 1],
    [1, 2],
    [2, 3],
    ...
  ]
}

Each edge is a pair of node indices [from_index, to_index]. See API Docs for the full schema.
