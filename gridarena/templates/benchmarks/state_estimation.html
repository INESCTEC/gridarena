Estimate JSON Format

The estimate file should contain grid_id, timestamp, and estimates (a list of objects):

  "grid_id": "masked_grid_abc",
  "timestamp": "2025-07-01T12:00:00",
  "estimates": [
    {"masked_node_id": "m_node_1", "voltage_magnitude": 229.5, "voltage_angle": 0.02},
    {"masked_node_id": "m_node_2", "voltage_magnitude": 228.1, "voltage_angle": -0.01}
  ]
}
