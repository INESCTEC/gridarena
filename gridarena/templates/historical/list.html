Historical

Upload, inspect and manage historical databases -- named collections of standalone power/voltage series that share one timeline.

Unlike Measurements (which requires a registered grid and node for every reading), a Historical database is just an ID with a shared list of timestamps, plus any number of series ("historicals") that each report power and/or voltage values at those same timestamps. Every series in a database is required to use that same timeline -- you can't upload a value at a datetime the database hasn't declared. Each series can hold power values, voltage values, or both, and is tagged with the grid level (MV, LV, or Feeder) it's meant for. You only ever upload whole databases; a database can contain as many series as you like.

Upload Historical Database

Upload a JSON file: database_id, optional name/description, a timestamps list (the shared timeline), and a historicals list -- each entry has a series_id, grid_level ("MV", "LV", or "Feeder"), and a values list whose datetimes must all be members of timestamps. Each value needs power fields (power_active/power_reactive), voltage fields (voltage_magnitude/voltage_angle), or both.
